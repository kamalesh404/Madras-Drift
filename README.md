# Madras Drift 🏎️🕸️

![Godot Engine](https://img.shields.io/badge/Godot_4.2.2-blue?logo=godotengine&logoColor=white)
![Status](https://img.shields.io/badge/Status-Under_Development-orange)

**Madras Drift** is an open-world, third-person driving and exploration game currently under active development. Step into the shoes of Spider-Man and explore a massive free-roam environment (featuring the iconic Clock Tower map), drive high-performance vehicles, and experience dynamic 3D physics!

### ✨ Features (So far)
*   **Play as Spider-Man**: Fully animated third-person character controller.
*   **Open World Exploration**: Explore the massive scaled-up Clock Tower map with full terrain and building collisions.
*   **Drivable Vehicles**:
    *   **Toyota GR86**: A custom-tuned drift car with realistic suspension and tire slip physics.
    *   **Suzuki GSX 750**: A fast, physics-stabilized sport bike.
*   **Dynamic Camera System**: Smooth third-person camera that intelligently tracks the player and swaps to vehicles upon entering.
*   **Beautiful Environment**: Procedural sky, dynamic sun shadows, atmospheric fog, and cinematic bloom lighting.

### 🚧 Under Development
This project is in its early stages. Future updates may include:
- Engine sounds and tire screeching audio
- Minimap and UI elements
- Additional maps and cities
- Traffic, NPCs, and missions
- Advanced drifting mechanics and scoring

### 🎮 Controls
*   **W / A / S / D**: Move character / Steer and accelerate vehicles
*   **Space**: Jump (Player) / Handbrake (Vehicles)
*   **Shift**: Sprint
*   **F**: Enter / Exit Vehicles
*   **Mouse**: Look around

### 🛠️ Built With
*   **[Godot Engine 4.2](https://godotengine.org/)** - The open-source 3D game engine.
*   **GDScript** - For all game logic, physics, and camera control.
